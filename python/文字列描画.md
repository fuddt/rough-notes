Pillow（PIL）なら ImageDraw でできます。

既存画像に「黒背景＋白文字」を描く例

from PIL import Image, ImageDraw, ImageFont
# 画像を開く
img = Image.open("input.png").convert("RGB")
# 描画用オブジェクトを作成
draw = ImageDraw.Draw(img)
# 表示したい文字列
text = "Hello PIL"
# 文字の表示位置
x, y = 50, 50
# フォント設定
# 日本語を使わないなら load_default() でもOK
font = ImageFont.load_default()
# 文字サイズを取得
bbox = draw.textbbox((x, y), text, font=font)
# bbox = (左, 上, 右, 下)
left, top, right, bottom = bbox
# 余白
padding = 8
# 黒背景を描画
draw.rectangle(
    [
        left - padding,
        top - padding,
        right + padding,
        bottom + padding
    ],
    fill="black"
)
# 白文字を描画
draw.text(
    (x, y),
    text,
    fill="white",
    font=font
)
# 保存
img.save("output.png")

日本語を表示したい場合

ImageFont.load_default() だと日本語が表示できないことがあります。日本語フォントを指定します。

from PIL import Image, ImageDraw, ImageFont
img = Image.open("input.png").convert("RGB")
draw = ImageDraw.Draw(img)
text = "あいうえお"
x, y = 50, 50
# Windows例
font_path = "C:/Windows/Fonts/meiryo.ttc"
# Mac例なら例えば：
# font_path = "/System/Library/Fonts/ヒラギノ角ゴシック W3.ttc"
font = ImageFont.truetype(font_path, size=32)
bbox = draw.textbbox((x, y), text, font=font)
left, top, right, bottom = bbox
padding = 8
draw.rectangle(
    [
        left - padding,
        top - padding,
        right + padding,
        bottom + padding
    ],
    fill="black"
)
draw.text(
    (x, y),
    text,
    fill="white",
    font=font
)
img.save("output.png")

ポイントはこの流れです。

文字サイズを取得
↓
文字サイズより少し大きい黒い四角を描く
↓
その上に白文字を描く

単純に「画像全体を黒背景にして白文字」ならこうです。

from PIL import Image, ImageDraw, ImageFont
# 黒背景の画像を新規作成
img = Image.new("RGB", (640, 360), "black")
draw = ImageDraw.Draw(img)
text = "Hello PIL"
font = ImageFont.load_default()
# 白文字を描画
draw.text(
    (50, 50),
    text,
    fill="white",
    font=font
)
img.save("output.png")
